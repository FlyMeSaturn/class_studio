## 자료 추가·수정

`content/catalog.json`이 수업 정보와 자료 목록의 정본입니다. 템플릿을 수정하지 않고 PPT·활동지·학생 산출물 파일이나 패들렛 같은 외부 링크를 추가합니다.

- `id`: 게시 후 유지하는 고유 영문 ID. 수업 주소는 `lessons/<id>/`입니다.
- `part`: `inquiry`(1부) 또는 `integration`(2부). `order`는 부 안의 표시 순서입니다.
- `status`: `published`는 실제 자료가 있는 항목, `preparing`은 소개와 준비 안내, `draft`는 사이트에서 제외합니다. 공개 저장소의 초안에도 비공개 정보를 넣지 않습니다.
- `files`: 공개할 파일만 `public/files/<lesson-id>/`에 복사하고 등록합니다. 파일 크기는 빌드가 읽습니다. 형식과 확장자는 일치해야 합니다.
- `links`: `label`과 HTTPS `url`로 외부 자료를 등록합니다. 새 탭에서 열리며 쿼리·프레임 주소를 그대로 보존합니다.
- `photos`: `path`, `alt`, `width`, `height`로 갤러리 이미지를 등록합니다. WebP·PNG·JPG를 지원합니다.
- `artifacts`: `id`, `label`, `path`, `alt`, `width`, `height`로 산출물 이미지를 등록합니다. 수업의 ‘학생 산출물 보기’ 버튼은 `lessons/<lesson-id>/artifacts/`의 갤러리로 이동합니다. 클릭 확대·이전/다음·화살표·Escape 닫기와 뒤로 가기를 지원합니다. ID는 같은 수업 안에서 중복되지 않아야 합니다.
- `planPages`: PDF를 쪽별 이미지로 렌더링한 `path`, `width`, `height` 목록입니다. 같은 항목의 `files`에 원본 PDF가 있어야 합니다.
- `updated`: 소개·게시 정보 확인일입니다. 원본 문서 수정일과 구분합니다.

자료 등록 예시(실제 파일 경로로 바꿉니다):

```json
{
  "status": "published",
  "files": [
    { "label": "수업 PPT", "format": "PPTX", "path": "files/pressure-and-weather/slides.pptx" },
    { "label": "학생 산출물", "format": "PDF", "path": "files/pressure-and-weather/student-work.pdf" }
  ],
  "links": [
    { "label": "[패들렛] 수업 활동", "url": "https://padlet.com/example" }
  ]
}
```

기존 `files`·`links` 배열에 항목을 추가합니다. 위 예시로 기존 지도안 정보를 덮어쓰지 않습니다. PDF는 열기/다운로드, 다른 추가 파일은 다운로드를 제공합니다. 자료가 외부 링크만 있어도 공개할 수 있습니다.

지도안은 수업별로 해당 원고 전체를 분리한 HWPX와 이를 한글 2024로 변환한 PDF입니다. 취합본의 앞부분과 다른 수업에 쓰인 내장 이미지는 제외했습니다. PDF 렌더 이미지를 쪽별로 표시하므로 모바일에서도 PDF 플러그인 없이 읽습니다. 크게 보기·쪽 이동·원본 PDF 열기와 좌하단 고정 뒤로 가기를 제공합니다. 전체 자료집으로 잘못 안내하지 않습니다.

갤러리는 수업 장면에 있는 이미지 35장(3/16/8/2/6장)입니다. 원고에 포함된 QR·활동지·산출물 이미지도 유지하며, 수학 이미지는 원고의 회전 정보를 반영합니다. 클릭 확대, 이전/다음, 좌우 화살표, Escape 닫기를 지원합니다. 기존에 충분히 모자이크된 사진은 유지하고, 추가 처리가 필요한 수학·음악·영어·중3 과학 사진 6장은 학생 얼굴을 모자이크했습니다. 얼굴 외 영역의 원본 픽셀은 유지합니다. 같은 사진의 지도안 HWPX·PDF·쪽별 보기에도 반영했으며, 수정 전 파일은 현재 배포에서 제외하고 새 주소로 제공합니다. 앞으로 사진을 추가할 때도 얼굴 처리를 확인합니다.

`source`는 원고 확인을 위한 내부 근거이며 화면에 출처·이용 안내 블록을 표시하지 않습니다. 공개 라이선스를 임의로 지정하지 않습니다. 등록하지 않은 파일, 연구비·정산·통장사본·참관 등록부 등은 복사하지 않습니다. 공개 자료는 사용자가 지정한 범위만 추가합니다.

## 배포와 검증

기본 브랜치 `main`에 반영하면 `.github/workflows/pages.yml`이 테스트 → 빌드 → 내부 링크·자산·파일 허용 목록 검사 → GitHub Pages 배포를 수행합니다. PR은 검증만 수행합니다. Settings → Pages → Source는 GitHub Actions를 사용합니다. 이전 버전은 `git revert`로 복원합니다.

파일과 이미지 모두 카탈로그에 등록되고 공개 상태인 것만 `dist/`에 복사합니다. 단일 파일 50 MiB, 사이트 950 MiB 초과를 차단합니다. 현재 배포 산출물은 약 23.85 MiB입니다.

모든 상세·지도안·사진 화면은 실제 `index.html`로 생성하여 직접 접근과 새로고침을 지원합니다. 링크와 CSS/JS에는 빌드 내용별 버전 값을 붙이고, canonical과 파일 주소는 유지합니다. 모든 내부 경로는 `/class_studio/` 기준입니다. 없는 주소는 `404.html`로 안내합니다.

수업 상세 화면은 교과·학년·수업명을 같은 줄에 배치합니다. PC에서는 작성자·수업 개요·수업 활동이 왼쪽, 모든 자료 버튼이 오른쪽 한 목록에 놓입니다. 작은 화면에서는 버튼 목록을 위로 쌓습니다. 자료 종류별 별도 제목을 붙이지 않습니다.

홈은 메인 이미지와 슬로건만 표시하는 한 화면이며 스크롤하지 않습니다. 상단 메뉴의 소개·수업자료·자료집은 각각 `about/`·`library/`·`collection/` 독립 페이지로 이동합니다. 홈에는 푸터나 고정 이동 버튼을 표시하지 않습니다. 다른 모든 페이지에는 좌하단 뒤로 가기와 우하단 HOME을 제공합니다. 뒤로 가기는 자료 보기에서 해당 수업으로, 수업 상세에서 해당 부의 수업 목록으로, 소개·목록·자료집에서 메인으로 돌아갑니다.

뒤로 가기는 HOME과 같은 브라운 캡슐형 버튼입니다. 본문의 중복 목록 복귀 링크는 제거했습니다. 작성자는 수업 개요·활동 아래에 표시하며 이솔 선생님은 ‘작성자 전주양현중학교 이솔’로 표기합니다. 목록 위의 일괄 자료 준비 안내 문구도 제거했습니다.

로고 설명 문구와 수업공방 글자의 폭을 맞추고 펜 끝과 글자 아래선을 정렬했습니다. 원본 PNG는 유지하면서 펜·글자를 각각 같은 비율로 조절한 CSS 마스크를 사용합니다. 헤더 최소 높이는 PC 96px, 모바일 128px입니다. 헤더 양 끝을 뷰포트 기준으로 배치해 페이지별 스크롤바 유무가 달라도 로고와 메뉴가 움직이지 않습니다.

## 지도안 연구회 명칭 정정 · 2026-11-16

명칭 외의 본문·쪽수·서식·내장 이미지는 유지됩니다. 취합본 45쪽, 개별 지도안 7/9/8/7/10쪽을 검증했습니다. 원본의 수정 전 백업은 같은 원본 폴더의 `원본 백업`에 보존하며 게시하지 않습니다.
