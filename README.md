# 수업공방 일반화자료실

공개 주소: https://flymesaturn.github.io/class_studio/

1부 **개념 기반 탐구학습**, 2부 **교과융합**의 수업을 찾고 각 수업의 자료 화면으로 이동하는 정적 웹사이트입니다. Node.js 기본 모듈만 사용하며 별도 API·서버·유료 서비스가 필요하지 않습니다.

현재는 자료집 완성 전 단계입니다. 사용자 요청에 따라 **실제 수업 파일을 업로드하지 않았습니다.** 확인된 1부 수업 5개와 2부 프로젝트 2개의 소개만 게시하며, 다운로드 공간에는 준비 상태를 표시합니다. 파일 형식·크기·가짜 다운로드·임의의 라이선스를 만들지 않았습니다.

## 로컬 실행

Node.js 22 이상이 필요합니다. 의존성 설치는 없습니다.

```sh
npm test
npm run build
npm run check
npm run preview
```

http://127.0.0.1:4173/class_studio/ 에서 확인합니다. `dist/`는 빌드할 때 새로 생성되므로 직접 편집하지 않습니다.

## 자료 정보 수정

`content/catalog.json`이 수업 정보의 정본입니다. 템플릿이나 CSS를 바꾸지 않아도 수업 추가·수정·파일 게시가 가능합니다.

1. `lessons`에서 기존 수업 항목을 복사합니다.
2. `id`를 고유한 영문 소문자·숫자·하이픈으로 정합니다. 게시한 ID는 제목이 바뀌어도 유지합니다. 주소는 `lessons/<id>/`입니다.
3. `part`는 `inquiry`(1부), `integration`(2부) 중 하나로 지정합니다. `order`는 해당 부 안의 표시 순서입니다.
4. 실제 자료를 확인해 `title`, `subjects`, `grades`, `summary`, `author`, `source`, `tags`, `overview`, `activities`, `updated`를 입력합니다. 융합 교과는 배열에 모두 기록합니다. `updated`는 소개·게시 정보의 확인일이며 원본 파일 수정일과 다릅니다.
5. 파일이 없으면 `status: "preparing"`, `files: []`를 유지합니다. 사이트에서 소개와 준비 안내를 제공합니다.
6. 완전히 비공개인 항목은 `status: "draft"`로 정합니다. 목록·고유 페이지·사이트맵에서 제외합니다. **공개 GitHub 저장소에 입력한 내용은 코드로 보일 수 있으므로, 비밀·개인정보·내부 업무자료는 draft에도 넣지 않습니다.**

상단 메뉴는 소개 → 수업자료 → 자료집 순서이며, 모든 페이지 우하단의 HOME 버튼으로 메인에 돌아갑니다. 현재 수업 수에 맞춰 검색·필터는 제거했습니다. 두 부의 바로가기와 수업 카드로 이동합니다. 예전 검색 쿼리가 주소에 남아 있어도 전체 수업을 표시합니다.

## 실제 파일을 공개할 때

현재는 업로드하지 않습니다. 아래 절차는 완성된 파일의 공개를 결정한 뒤 사용합니다.

1. 최종본·작성자·개인정보·외부 저작물·이용 범위를 확인합니다. 파일명과 수정일만으로 최종본을 판단하지 않습니다.
2. 공개할 파일만 `public/files/<lesson-id>/`에 복사합니다. 로컬 수업공방 폴더 전체를 복사하지 않습니다. 경로는 영문·숫자·하이픈을 권장합니다.
3. 해당 수업에 `usage`로 **확인된 이용 안내**를 입력하고, `status`를 `published`로 변경합니다. `files`에 실제 파일을 등록합니다.

```json
{
  "status": "published",
  "usage": "여기에 작성자와 확인한 이용 안내를 입력합니다.",
  "files": [
    { "label": "수업 지도안", "format": "PDF", "path": "files/수업ID/lesson-plan.pdf" }
  ]
}
```

위 코드는 입력 형식 설명이며 실제 파일이나 공개 허락을 뜻하지 않습니다. 경로의 `수업ID`는 영문 ID로 바꿉니다. **제공하는 형식만** 등록합니다. `bytes`는 입력하지 않아도 빌드에서 실제 파일 크기를 읽습니다. PDF는 열기와 다운로드, 다른 파일은 다운로드 링크를 제공합니다. 수업 전체 ZIP은 실제 구성을 확인하고 유용할 때만 별도 파일로 등록합니다.

전체 자료집도 `collection`의 `status`, `description`, `usage`, `files`를 같은 방식으로 수정합니다. 공개 시 자료집 안내 문구도 최종 상태에 맞게 고칩니다.

빌드는 `public/`를 통째로 복사하지 않습니다. 사이트 자산과 **공개 상태 항목에 등록된 파일만** 배포합니다. 다만 저장소 자체가 공개이므로 게시하지 않을 자료를 저장소에 추가해서는 안 됩니다. 연구비·정산·통장사본·참관 등록부·타 연구회 자료·학생 식별 정보는 제외합니다.

## 배포

기본 브랜치 `main`에 반영하면 `.github/workflows/pages.yml`이 실행됩니다.

1. 메타데이터·공개 상태·파일 경로 테스트
2. 모든 고유 URL을 실제 HTML로 생성
3. 내부 링크·이미지/글꼴·하위 경로·파일 허용 목록 검사
4. GitHub Pages 배포

PR에서는 검증과 빌드만 수행합니다. 저장소 **Settings → Pages → Source: GitHub Actions**를 사용합니다. 공개 범위를 임의로 변경하지 않습니다. 실패하면 Actions의 해당 실행에서 원인을 확인하고 수정한 뒤 다시 실행합니다. 이전 버전 복원은 문제 커밋을 `git revert`한 뒤 `main`에 반영합니다. 기록을 강제로 덮어쓰지 않습니다.

상세 페이지는 `lessons/<id>/index.html`로 생성되어 주소 직접 접근과 새로고침을 지원합니다. 내부 페이지 이동 링크에는 배포 내용에 따른 `v` 값을 붙여 이전 HTML 캐시와 새 자산이 섞이는 문제를 줄이며, canonical 주소와 실제 파일 URL은 유지합니다. 없는 주소는 Pages의 `404.html`로 안내합니다. 모든 내부 경로는 `/class_studio/`를 기준으로 만듭니다. 저장소 이름 또는 호스트 변경 시 `scripts/catalog.mjs`의 `base`, `origin`도 변경해야 합니다.

## 용량

현재 빌드는 약 2.22 MB이며 대부분은 자체 호스팅 글꼴입니다. 실제 수업 파일은 0개입니다. 확인한 1부 취합 HWPX는 약 13.5 MiB지만 미완성 원고로 업로드하지 않았습니다.

프로젝트는 단일 파일 **50 MiB** 초과를 차단하고, 사이트 **950 MiB** 초과도 차단합니다. 이는 GitHub의 상한에 여유를 둔 자체 기준입니다. 큰 자료집은 압축·분할 등을 검토하고, GitHub Releases로 제공할 필요가 생기면 비로그인 접근·영구 URL·출처·용량을 확인한 뒤 외부 파일 지원을 추가합니다. 현재는 임시 서명 URL이나 외부 파일을 등록하지 않습니다.

GitHub Pages: 게시 사이트 최대 1 GB, 월 대역폭 소프트 한도 100 GB. GitHub Free에서는 공개 저장소에서 사용할 수 있습니다. [공식 제한 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

## 콘텐츠 근거와 디자인

- 1부: 개념 기반 탐구학습 지도안 취합 원고에서 수업명·교과·대상·교사·활동을 확인했습니다. 11월 8일 편집 변형본보다 취합본의 수정 시점이 뒤이지만, 최종본으로 확정하지 않았습니다.
- 2부: 사용자가 지정한 「전북교육」 제71호 수업공방 소개 원고에서 두 프로젝트의 제목과 구성을 확인했습니다. 중3 대상은 연구회 개발자료 소개와 교차 확인했습니다. 원고의 연락처·사진·모집 안내 등은 게시하지 않았습니다.
- 소개: 자료집 여는 글과 연구회 소개 원고를 바탕으로 성과를 과장하지 않는 문구를 작성했습니다.
- [아르떼 라이브러리](https://lib.arte.or.kr/): 한글 정보 위계, 검색과 분류, 자료 묶음.
- [MoMA Art terms](https://www.moma.org/collection/terms/): 분류 바로가기와 명확한 타이포그래피, 여백.
- [It's Nice That](https://www.itsnicethat.com/): 편집형 제목·분류와 목록 간격.
- [Collective Gallery](https://www.collective-edinburgh.art/): 첫 화면을 채우는 이미지, 간결한 메뉴와 넓은 여백. 현재 메인 디자인에 반영했습니다.
- 실제 수업공방 로고와 새로 생성한 메인 이미지의 출처·프롬프트는 [이미지 기록](docs/image-assets.md)에 있습니다. 원본 로고 PNG를 보존하고 CSS로 투명 여백을 제외한 뒤 브라운으로 표시합니다.
- 문구는 humanizer-kr 스킬로 두 차례 검토했습니다. [교정 기록](docs/copy-review.md).
- Impeccable 공식 CLI로 프로젝트 스킬을 설치하고 설계·렌더링 검토·최종 검사를 참고했습니다. 사용자의 자율 구현 요청을 우선하여 추가 디자인 승인 단계는 만들지 않았습니다. 설치한 도구와 바이너리는 Git에서 제외합니다.
- 글꼴: [Pretendard v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9), SIL Open Font License 1.1. `public/assets/fonts/OFL.txt`에 원문을 포함합니다. **글꼴의 라이선스는 수업 자료의 이용허락과 별개입니다.**

공개 파일이 없으므로 실제 수업 PDF/HWPX 다운로드 검증은 공개 시 추가로 수행해야 합니다. 화면·고유 주소·준비 상태와 변경 이력의 검증 기록은 `docs/verification.md`를 참고합니다.
