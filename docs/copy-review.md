# 사이트 문구 검토

2026-11-15 · 적용 스킬: humanizer-kr 1.1.0

## 수정 기준

공식 교육자료실에 맞는 문체를 유지하되, 추상적인 도입과 같은 내용을 반복하는 설명은 삭제했습니다. 수업명·작성자·교과·학년·수업 활동의 사실은 보존했습니다. ‘개기탐’ 표기와 검색은 사용자의 요청에 따라 없앴습니다.

## 1차 교정

- “함께해 본 수업을 나눕니다”, “개념을 탐구하고, 교과를 연결하며” 등 홍보 문장 삭제.
- 각 부의 추상적인 설명과 중복 부제 삭제. 분류명만 표시.
- “이렇게 이어 갑니다” → “수업 활동”, “수업 이야기” → “수업 개요”.
- 자료 준비 안내를 한 문장으로 줄임.
- 소개 화면의 수사적인 도입과 반복 설명 삭제.

## 2차 검토와 최종 교정

1차 교정 뒤에도 카드 소개의 연결어미와 추상적인 표현이 반복되어 실제 활동을 중심으로 다시 썼습니다. 교육자료실의 문구이므로 사적인 감정이나 대화체를 추가하지 않았습니다.

| 기존 | 최종 |
| --- | --- |
| 일상 속 물체의 변화를 관찰하고 분류하며 힘의 개념을 만들고, 화살표로 힘을 표현합니다. | 생활 속 힘의 사례를 분류하고 힘의 크기와 방향을 화살표로 나타냅니다. |
| 민요에서 지켜 온 것과 바뀐 것을 찾고, 장단과 가락에 맞춰 학교생활을 담은 노랫말을 만듭니다. | 옹헤야와 통영개타령을 배우고 학교생활을 담은 노랫말로 바꿔 부릅니다. |
| 세계 시장의 문화를 비교하고, 독자와 목적을 고려한 한국 여행 안내서를 만듭니다. | 세계 시장의 문화를 비교하고 외국인을 위한 한국 여행 안내서를 만듭니다. |
| 지도안·활동지·수업자료를 정리하고 있습니다. 완성된 파일과 이용 안내를 확인한 뒤 이곳에 공개합니다. | 자료 준비 중입니다. |

‘언어라는 창을 통해 세계 문화를 탐구하고 서로의 마음을 잇기’ 등 원고에서 확인한 실제 수업명은 임의로 바꾸지 않았습니다. 최종 문구는 content/catalog.json과 scripts/build.mjs에서 관리합니다.
